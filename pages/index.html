Kindle apps

KPM packages for jailbroken Kindles, by predakanga.

You need a jailbroken Kindle with KPM installed. With Wi-Fi on, in kterm or over SSH on the Kindle, add this repository once:

kpm add-repo @INDEX_URL@
kpm update

Then install any of these with kpm install, and upgrade by running kpm update and the same kpm install again.
